# SNES Flow Android v0.1.0

Protótipo de emulador SNES para Android com importação de ROMs `.sfc`, `.smc` e `.fig` via seletor nativo, controles touch completos, gamepad físico, SRAM automático, save/load state e patch opcional `.ips`. ROMs e patches comerciais não são incluídos.

O frontend usa LibretroDroid (GPL-3.0). O core Snes9x possui licença de uso não comercial. Este protótipo é destinado a uso pessoal/testes.
